
# 📊 Uranium Equity Statistical Arbitrage

### EPAT Quantitative Research Project | CCJ vs UEC

---

## 🚀 Project Overview

This project explores statistical arbitrage opportunities in the uranium equity market using two publicly traded companies:

- **CCJ:** Cameco Corporation
- **UEC:** Uranium Energy Corp.

The objective is to investigate the statistical relationship between these two equities and explore potential pairs-trading opportunities using Python and quantitative analysis.

## 🎯 Research Objectives

- Analyse historical stock price movements.
- Study the relationship between CCJ and UEC.
- Investigate spread behaviour.
- Explore mean-reversion opportunities.
- Evaluate statistical arbitrage trading signals.
